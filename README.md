## Sobre mí

Soy desarrolladora de software enfocada principalmente en el **desarrollo web full stack**.

Trabajo entendiendo el ciclo completo de una aplicación: análisis del problema, requerimientos, experiencia de usuario, lógica de negocio, modelado de datos, implementación, validaciones, seguridad, pruebas, control de versiones y despliegue.

Me interesa especialmente construir sistemas que contemplen situaciones reales y no únicamente el *happy path*: errores de usuario, estados inconsistentes, permisos, excepciones, trazabilidad y flujos completos de operación.

Actualmente estoy desarrollando **Nodo**, una plataforma de gestión para servicios técnicos con arquitectura multiusuario y multi-organización.

# Proyectos destacados

## Nodo — Plataforma de gestión para servicios técnicos

> **Actualmente en desarrollo**

Aplicación web full stack diseñada para digitalizar y centralizar el ciclo completo de trabajo de un servicio técnico, desde la recepción de un dispositivo hasta su diagnóstico, presupuesto, reparación, cobro y entrega.

La plataforma está siendo diseñada con una arquitectura **multiusuario y multi-organización**, permitiendo que diferentes talleres administren sus operaciones y datos de manera independiente.

### Funcionalidades principales

* Gestión de organizaciones, usuarios, roles y permisos.
* Recepción y seguimiento de dispositivos.
* Administración de clientes y sus equipos.
* Diagnósticos técnicos.
* Presupuestos y aprobación de reparaciones.
* Seguimiento del ciclo completo de órdenes de servicio.
* Gestión de inventario y repuestos.
* Alertas y niveles de stock.
* Historial de estados y trazabilidad.
* Gestión de cobros y entregas.
* Portal de seguimiento para clientes.
* Configuración inicial personalizada por organización.
* Autenticación y políticas de seguridad.

## Cómo trabajo

Mi proceso parte de comprender el problema antes de implementar una solución.

**1. Análisis**
Identifico necesidades, actores, reglas de negocio, casos límite y restricciones.

**2. Diseño**
Defino flujos de usuario, interfaz, estructura de datos y responsabilidades del sistema.

**3. Arquitectura**
Selecciono tecnologías según el contexto y organizo frontend, backend, datos, autenticación y servicios.

**4. Implementación**
Desarrollo de forma progresiva, priorizando componentes reutilizables, validaciones y consistencia.

**5. Validación**
Compruebo no solamente el flujo esperado, sino también errores, permisos, estados inválidos y situaciones excepcionales.

**6. Despliegue e iteración**
Versiono los cambios, configuro el entorno de ejecución y continúo refinando la solución a partir de pruebas y nuevas necesidades.
